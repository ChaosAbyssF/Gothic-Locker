# 哥特王朝开锁工具 - 使用说明
## 一、工具简介
本程序基于**广度优先搜索(BFS)** 自动求解《哥特王朝 remake》游戏连锁锁具，根据模块联动规则、初始位置，计算出从当前状态解锁至**所有模块居中（位置4）** 的完整操作步骤，并以直观中文+箭头形式展示操作流程。

规则说明：
1. 模块共5个，每个模块位置范围：`1 ~ 7`，目标位置：`4`（中间孔）
2. 移动定义：`+1 = 左移`，`-1 = 右移`
3. 移动模块会触发联动，越界（位置<1 或 >7）的操作会自动判定无效

## 二、文件结构
```
lock_solver.py   # 主程序（求解逻辑 + 渲染函数）
README.md        # 使用说明文档
```

## 三、参数配置
打开 `lock_solver.py`，修改两处核心参数即可适配当前游戏锁状态：
1. **初始状态**
```python
# 按 1~5号模块顺序填写当前位置
initial_config = [6, 2, 1, 1, 5]
```
2. **联动规则**
默认已配置游戏原版联动规则，如需修改规则，编辑 `game_rules` 字典即可：
```python
game_rules = {
    1: [],                # 移动模块1：仅自身移动
    2: [(3, 1), (5, 1)],  # 移动模块2：3、5号同向联动
    3: [(5, 1), (1, -1)], # 移动模块3：5号同向、1号反向联动
    4: [(3, -1)],         # 移动模块4：3号反向联动
    5: [(2, 1)]           # 移动模块5：2号同向联动
}
```

## 四、运行方式
1. 确保环境安装 **Python 3.6+**（无需额外第三方库）
2. 找到一个游戏中的上锁箱子，并**保存你的游戏**
3. 尝试获取锁具的左右规则，修改脚本中的`initial_config`以及`game_rules`，随后运行脚本：
   ```bash
   python lock_solver.py
   ```

## 五、输出结果说明
程序会依次输出：
1. 原始初始状态、最终解锁状态
2. 分步操作指令（**每行一条操作**）
   - `左移`：对应箭头 `←`
   - `右移`：对应箭头 `→`
   - 数字代表连续移动次数

### 示例输出
```
初始状态: [6, 2, 1, 1, 5]
最终状态: [4, 4, 4, 4, 4]
模块2 左移1次 ←
模块3 左移1次 ←
模块1 右移2次 →→
模块4 左移2次 ←←
模块5 左移3次 ←←←
```

## 六、使用注意事项
1. 严格按照输出**从上到下依次操作**模块，顺序不可颠倒
2. 程序会自动过滤越界操作，输出步骤均为游戏内可执行的合法操作
3. 若输出 `无法找到开锁步骤`，代表当前状态+规则下无解锁方案，请核对游戏内模块初始位置
4. 联动效果由程序自动计算，无需手动处理连带移动，只需执行**主模块**操作即可
